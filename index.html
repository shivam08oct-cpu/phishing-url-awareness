What this tool checks
🔗

@ Symbol

Browsers discard everything before @, hiding the true destination host.

📏

Long URLs

URLs over 100 characters often embed redirect paths designed to confuse users.

🌐

IP Address

Legitimate sites almost never use a bare IP address — it bypasses domain registration.

🔀

Subdomains

Five or more hostname segments can disguise the real domain at the end of the chain.

🌍

Punycode

xn-- prefixes encode look-alike Unicode letters to spoof brand names.

🔓

HTTP (not HTTPS)

Unencrypted traffic is easier to intercept. HTTPS alone still doesn't guarantee trust.
